# GPT Architecture from Scratch (Vanilla Transformer Implementation)

A custom, decoder-only generative language model implementation built using **PyTorch** to demonstrate core deep learning and NLP mechanics.

## 🛠️ Technical Keywords & Architecture
* **Core Framework:** PyTorch, Python, NumPy
* **Architecture:** Vanilla Transformer (Decoder-only configuration), Scaled Dot-Product Multi-Head Self-Attention
* **Normalization & Optimization:** LayerNormalization, Residual Connections, AdamW Optimizer, Cross-Entropy Loss
* **Data Pipeline:** Custom character-level/sub-word tokenization and positional embeddings vectors
